# CAOCAP

CAOCAP is a spatial software-learning studio where builders create and understand
Mini-Apps with a human-in-the-loop CoCaptain.

## Language

**Review Bundle**:
The ordered set of CoCaptain-proposed Mini-App edits and app actions from one turn, presented under one canonical identity for human decisions.
_Avoid_: Review card, pending bundle, change list

**Review Lifecycle**:
The process that stages a typed draft into a Review Bundle and owns clarification, approval, rejection, conflict outcomes, checkpoints, and node-session persistence.
_Avoid_: Review flow, approval helper, review persistence
